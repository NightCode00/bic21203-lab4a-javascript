## Overview
This repository contains the solutions for Lab #4a, focusing on modern client-side JavaScript. The activities cover DOM manipulation, event handling, conditional input validation, and iterative element generation. 

## Instructions to Run
1. Clone this repository to your local machine.
2. Open `index.html` in any modern web browser.
3. **Question 1:** Click "Change Message" to see the DOM text update.
4. **Question 2:** Enter various test values (`5`, `10`, `15`, `abc`, empty space) and click "Check" to validate.
5. **Question 3:** Click "Generate" to dynamically build the ordered list without duplicating elements on repeated clicks.
